# 出版社稿酬结算与授权区域系统

面向编辑、财务、作者三类角色的稿酬结算系统：编辑维护作品合同（多作者分成、授权语种/区域、有效期、纸书与电子书费率）；财务按期导入销量并结算；作者登录查看本人计算明细与原始销量依据，减少邮件对账。

## 一条命令启动

```bash
./run.sh
# 打开 http://localhost:8080
```

首次启动自动建库、播种示例数据并导入两期示例销量。重复启动幂等（示例文件不会被重复导入）。
可通过环境变量改监听地址与数据库：`ADDR=:9090 DB=data/x.db ./run.sh`

## 一键验证业务规则

```bash
./verify.sh        # 临时库跑 51 项断言后销毁；加 --keep 保留 data/verify.db
```

覆盖：多作者精确分成（分币最大余数法无尾差）、重复导入整批拒绝 + 同渠道行跨文件去重、
跨区/超授权语种销售隔离、跨期退货隔离、合同到期后补传单列、按销售时点匹配合同版本、
确认单锁定金额、补差单关联原单、模拟付款回执、作者数据隔离。

## 技术栈

- 后端：Go + Gin + GORM，SQLite（`glebarez/sqlite` 纯 Go 驱动，**无需 CGO**）
- 前端：Vue 3 单文件 SPA（本地 `web/vendor/vue.global.prod.js`，**无需 npm 构建**）
- 存储：单文件 SQLite（默认 `data/royalty.db`），付款回执为本地模拟，无外部支付调用

## 命令

```bash
go run . serve  --addr :8080 --db data/royalty.db --web web   # 启动
go run . seed   --db data/royalty.db                          # 只写示例主数据
go run . verify [--keep]                                      # 业务断言
go run . reset  --db data/royalty.db                          # 清空重建
```

## 核心业务规则

1. **合同版本时点匹配**：每条销量按 `sale_date` 落在哪个合同版本的有效期内就用哪个版本（费率、区域、语种、分成均以该版本为准）。
2. **多作者分成**：分成比例以基点存储（合计必须 10000）。先算版税（销售额×费率，四舍五入到分），再用最大余数法拆分，作者合计与版税总额逐分相等。
3. **异常隔离**（不计入正常应付，单列展示）：
   - `cross_region`：销售区域或语种不在该期合同授权范围内（跨区销售）；
   - `cross_period_return`：退货（qty 为负）抵扣的原销售属于另一期，或找不到原销售；
   - `no_contract`：销售发生时无有效合同（如合同到期后补传），按最近合同版本仅供核对。
4. **幂等导入**：批次级用文件内容 SHA-256 唯一索引拒绝整批重复；行级用渠道行号 `ref` 唯一索引防止跨文件重复计酬；结算行 `(销量, 作者)` 唯一。
5. **确认锁定与补差**：草稿单随导入自动重算；确认后金额冻结，任何重算不触碰已确认行；差错只能开具补差单（正负均可）并关联原单，付款金额 = 正常稿酬 + 补差累计。
6. **确认后补录**：已确认期次补传的销量生成 `supplement` 补结算单并关联原单，不混入原单。

## 示例数据说明

作品《山河故人》（W001）：

- 合同 v1：2025-01-01 ~ 2025-07-01，仅大陆(CN)/简体(zh)，纸书 10%、电子书 15%，王明 60% / 李华 40%
- 合同 v2：2025-07-01 ~ 2025-10-01，新增台湾(TW)、英文(en)，纸书 12%

`data/sales-2025-06.csv`：正常纸书/电子书销售、台湾跨区销售、同期退货、零头分币用例。
`data/sales-2025-07.csv`：英文电子书（v2 授权）、香港跨区、7 月退 6 月销售（跨期退货）、
补传的 6 月销量（确认后补录）、10 月销量（合同到期后补传）。
`data/sales-dup-test.csv`：与 6 月文件含相同渠道行号，用于验证重复导入。

## CSV 格式

```
ref,work_code,sale_date,period,region,language,format,qty,unit_price,amount,original_ref
S001,W001,2025-06-10,2025-06,CN,zh,print,100,50.00,5000.00,
S004,W001,2025-06-20,2025-06,CN,zh,print,-10,50.00,-500.00,S001
```

`format` 为 `print`/`ebook`；退货数量与金额为负，并在 `original_ref` 指向原销售行号。
